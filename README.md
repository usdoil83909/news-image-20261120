Entry for the make.fun bounty **"Sum up 20 November's world news in one image"**:
a pure-stdlib Python program that renders a 1024x1024 PNG newspaper-style page
summarizing the day's world news.

`main.py` writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
Deterministic: two runs produce byte-identical output. No network, no third-party
packages. MIT licensed.
